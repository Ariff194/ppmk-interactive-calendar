# PPMK Interactive Calendar

**HackPPMK25 — Honorable Mention**

## Overview

PPMK Interactive Calendar is a collaborative event calendar designed to help students discover and organize student activities. The platform supports event submissions and an administrator approval workflow.

## Project Details

- **Project type:** Team project
- **Team size:** 5 members
- **Event:** HackPPMK25
- **Recognition:** Honorable Mention

## My Contributions

My responsibilities focused on user testing, feedback, and presentation preparation.

- Tested application features from a user's perspective to check whether they worked as expected.
- Shared observations with teammates during project development.
- Prepared presentation slides explaining the project's purpose and features.

## Technologies

The project used React, TypeScript, SQL, and Supabase. These are project-level technologies, not a claim that I personally implemented each one.
